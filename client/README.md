# Credit Scoring System — Frontend

🌐 **Live:** [https://my-credit-scoring-1.vercel.app](https://my-credit-scoring-1.vercel.app)

Next.js 16 frontend for the decentralized credit scoring system built on Stellar Soroban.

For full documentation, architecture, and smart contract details see the [root README](../README.md).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Requires Node.js v20.9+ and the [Freighter](https://freighter.app/) browser extension set to **Testnet**.
